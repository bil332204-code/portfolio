# bilal-ahmed-builds.cyou

Portfolio site for Bilal Ahmed: an animated static frontend plus a small serverless backend (contact form), deployed on Vercel.

```
portfolio/
├── public/                  ← everything visitors download (the frontend)
│   ├── index.html           homepage (doors, stacked cards, timeline, skills globe, contact form)
│   ├── resume.html          /resume  (has a "Save as PDF" button that prints cleanly)
│   ├── 404.html             shown for any wrong URL
│   ├── projects/*.html      /projects/<name>  ← GENERATED by npm run build, don't edit by hand
│   ├── assets/              site.css + main.js (homepage), page.css (other pages), resume.js
│   ├── images/              put bilal-ahmed.png here
│   ├── og.png               the preview image shown when the link is shared on WhatsApp/LinkedIn
│   ├── favicon.svg, apple-touch-icon.png, icon-512.png, site.webmanifest
│   ├── robots.txt, sitemap.xml (sitemap is generated)
├── api/                     ← the backend (Vercel serverless functions)
│   ├── contact.js           POST /api/contact → validates, blocks bots, emails you via Resend
│   └── health.js            GET  /api/health  → shows whether the backend is configured
├── scripts/
│   ├── content.mjs          ★ all project text lives here — edit this to change project pages
│   ├── build.mjs            turns content.mjs into project pages + sitemap
│   ├── serve.mjs            local server that behaves like Vercel (npm run local)
│   └── test-api.mjs         tests for the contact API (npm test)
├── vercel.json              clean URLs, redirects, security headers, caching
├── .env.example             the environment variables the backend needs
└── package.json
```

No frameworks, no dependencies to install. Needs Node 20 or newer only if you want to run it locally.

## Step 3 — Deploy on Vercel

1. vercel.com → sign up with GitHub → **Add New → Project** → import `portfolio`.
2. Framework preset: **Other**. Leave build/output settings alone — `vercel.json` already sets them
   (build command `npm run build`, output folder `public`).
3. Click **Deploy**. You get a `something.vercel.app` link in about a minute. Open it and click around.

From now on, every `git push` to `main` redeploys automatically, and every other branch gets its own preview link.

## Step 4 — Make the contact form send email (Resend, free)

1. Sign up at resend.com **with the Gmail you want messages delivered to**.
2. **API Keys → Create API key** (permission: Sending access). Copy it — it starts with `re_`.
3. Vercel → your project → **Settings → Environment Variables**, add for Production and Preview:
   - `RESEND_API_KEY` = the key
   - `CONTACT_TO_EMAIL` = the same email you signed up to Resend with
4. **Deployments → ⋯ → Redeploy** (env vars only apply to new deployments).
5. Visit `/api/health` → should say `"contactConfigured": true`. Then send yourself a test message from the form.

Until you verify a domain, Resend's test sender (`onboarding@resend.dev`) can only deliver to your own Resend account email — which is exactly what a contact form needs. Visitors' emails are set as **reply-to**, so you just hit Reply.

**Later (optional, nicer):** Resend → Domains → add `bilal-ahmed-builds.cyou`, add the DNS records it shows at your registrar, then set
`CONTACT_FROM_EMAIL = Portfolio <hello@bilal-ahmed-builds.cyou>` in Vercel and redeploy.

## Step 5 — Point your domain at Vercel

1. Vercel → project → **Settings → Domains** → add `bilal-ahmed-builds.cyou` and also `www.bilal-ahmed-builds.cyou`
   (set one to redirect to the other; apex as the main one is recommended).
2. Vercel shows the exact DNS records. Log in where you bought the `.cyou` domain → DNS settings:
   - **Delete** the old records that point to the ChatGPT-hosted site (any `A`, `AAAA`, `CNAME` on `@` and `www`).
   - Add `A` record: host `@` → the IP Vercel shows (usually `76.76.21.21`).
   - Add `CNAME` record: host `www` → the target Vercel shows (looks like `xxxx.vercel-dns-017.com`).
   - If there's an old `_acme-challenge` TXT record, delete it.
3. Wait 5 minutes to a few hours. Vercel turns the domain green and issues HTTPS automatically.
4. Check: `https://bilal-ahmed-builds.cyou`, `/resume`, `/projects/aegis-jd`, a fake URL (should show "Wrong door"), `/api/health`.

## Visitor log (who visited and when)

Every page load is saved to a private Vercel Blob store (`portfolio-visits`): time, page, city/country, device and browser, where they came from, and a short visitor ID (a scrambled code made from their network + browser; the IP itself is never stored).

- **See it:** https://bilal-ahmed-portfolio-outlaw7.vercel.app/visits (asks for your Vercel login). On the public domain `/visits` shows nothing.
- **Don't count yourself:** open `https://bilal-ahmed-builds.cyou/?me=1` once on each of your browsers (`?me=0` undoes it).
- **Track where a link was clicked:** add `?ref=linkedin` (or `?utm_source=cv`, etc.) to links you share; it shows under "Came from".
- Files: `public/assets/visit.js` (sends the visit), `api/visit.js` (saves it), `api/visits.js` (the dashboard). Needs `BLOB_READ_WRITE_TOKEN`, which Vercel adds automatically because the store is connected to the project.

## Private résumé / CV builder

Paste a job description, pick **Résumé** (1 page) or **CV** (full, 2–3 pages), and get a PDF tailored to that job.
The AI only picks, reorders and rewords facts from your profile. It never invents experience, and it lists the job's requirements you don't have so you can see the gaps.

- **Open it:** https://bilal-ahmed-portfolio-outlaw7.vercel.app/resume-builder (asks for your Vercel login). On the public domain it shows nothing, and the API refuses to run, so nobody else can use your AI quota.
- **One-time setup:** get a free Gemini key at aistudio.google.com/apikey → Vercel → project → Settings → Environment Variables → add `GEMINI_API_KEY` (Production + Preview) → redeploy. (Or `ANTHROPIC_API_KEY` for Claude.) If Google renames its models, set `GEMINI_MODEL`.
- **Your facts:** `api/_profile.js` (education, experience, skills, certificates) plus the projects in `scripts/content.mjs`. Add anything new there and push.
- Files: `api/resume-builder.js` (the page), `api/tailor.js` (makes the PDF), `api/_ai.js` (the prompt), `api/_pdf.js` (the layout).

## Troubleshooting

- **Form says "isn't set up yet"** → env vars missing, or you didn't redeploy after adding them.
- **Form says "couldn't be sent"** → Vercel → project → Logs, look for `contact: Resend error`. A 403 there means `CONTACT_TO_EMAIL` isn't your Resend account email.
- **Form says "only works on my site"** → you're posting from another domain; add it to `ALLOWED_ORIGINS`.
- **Domain stuck on "Invalid configuration"** → an old record is still there, or a proxy (orange cloud on Cloudflare) is on; set it to DNS only.
- **Photo shows "BA"** → `public/images/bilal-ahmed.webp` is missing or named differently (case matters).
- **Something blocked in the browser console mentioning Content-Security-Policy** → you added a script/font from a new site; add that site to the CSP line in `vercel.json`.
