What it does

A self-contained browser app that layers a smooth Mandelbrot set with recursive trees, Sierpinski triangles, nested hexagons and logarithmic spirals.

How it works

  1. RenderEscape-time iteration over complex numbers draws the Mandelbrot background.
  2. GrowRecursive functions draw the trees, triangles and hexagons on top.
  3. VaryA seeded random generator makes every composition reproducible.
  4. ExportPictures export as 2000 × 2500 PNG files, with no external libraries.
